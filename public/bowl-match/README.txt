bowl match — 내 취향의 샐러드

HTML, CSS, JavaScript와 전체 사진 파일이 포함되어 있습니다.
재료 카드 사진 18종, 스와이프 중 다음 카드 미리보기 기능을 포함합니다.

실행 방법
1. 압축을 풉니다.
2. bowl-match 폴더에서 터미널을 열고 다음 명령을 실행합니다.
   python -m http.server 8000
3. 브라우저에서 http://localhost:8000 을 엽니다.

간단히 확인하려면 index.html을 브라우저로 열어도 됩니다.
정적 웹 호스팅에 올릴 때는 폴더 안의 파일을 그대로 업로드하세요.

카드를 오른쪽으로 넘기면 재료를 추가하고, 왼쪽으로 넘기면 건너뜁니다.
카드를 조금 기울이면 다음 재료의 사진과 정보가 보입니다.
화살표 키로 선택하고, 되돌리기 버튼으로 이전 선택을 바꿀 수 있습니다.
선택한 조합은 브라우저에 저장되며 실제 주문·결제는 이루어지지 않습니다.
완성 샐러드 사진은 선택한 재료와 비슷한 조합의 참고 이미지입니다.
leaf & bowl 링크는 쇼핑몰 메인(/)으로 이동합니다. (saladay 쇼핑몰의 public/bowl-match/ 에서 /bowl-match/index.html 로 제공)
